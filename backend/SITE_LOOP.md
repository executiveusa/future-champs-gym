# Future Champs Autonomous Site Loop

This is the operating contract for Instinct → FirstMate → Hermes.

## Command chain

**Glenn / owner → Instinct → FirstMate → Hermes.**

Instinct may direct the work. FirstMate controls boundaries, context, approvals, and handoffs. Hermes executes bounded work in isolated branches/worktrees. The builder never reviews itself.

## What the loop should do without asking

- inspect the current public shell;
- reduce unnecessary copy and UI;
- improve mobile layout and navigation;
- maintain all 19 video placeholders;
- keep The Corner, Watch, and homepage coherent;
- prepare real media records from the canonical Drive archive;
- fix broken internal links;
- improve accessibility and semantic HTML;
- run the Collins / Future Champs / anti-slop gauntlet;
- request an independent-agent review;
- merge non-destructive site improvements only after that review passes;
- update ICM context and the agent log after every cycle.

## What the loop must not do without approval

- publish youth footage;
- publish a new identity, biography, affiliation, sponsor, result, fundraiser, event, or factual claim that has not been approved;
- expose private Drive URLs beyond the already locked source reference;
- change credentials, domains, production data, or destructive backend state;
- remove rollback.

## Current build target

The public experience is a media property, not a gym-management product.

1. **Homepage** — point of view and strongest path into Watch.
2. **Watch** — 19-slot video shelf with Anchor 001 leading.
3. **The Corner** — editorial desk for interviews, profiles, and field notes.
4. **Media records** — source → transcript → captions → cut → review → publish.
5. **Distribution** — YouTube/Shorts only after the manual publish path is proven.

## Definition of shell-ready

The shell is ready when:

- all three primary pages feel like one brand;
- mobile works without horizontal overflow or hidden essential navigation;
- every CTA resolves;
- empty states are intentional;
- no fake people, metrics, videos, quotes, or claims appear;
- approved media can replace a placeholder without a redesign;
- an independent reviewer passes user value, design, accessibility, claims, and rollback.
