# Full Audit and Plan — Future Champs

**Date:** 2026-09-16  
**Baseline:** brownfield static site, reframing in progress

## Audit headline

The repo has a strong strategy and visual direction, but the public product is still a static prototype. The next risk is not styling; it is wiring proof, rights, content records, and one real publishable story.

## Current strengths

- Clearer position: youth and beginning-fighter stories.
- Governing idea drafted: “Every fighter starts somewhere.”
- Private video source locked to Google Drive.
- Content multiplication model documented.
- Existing black, bone, and red editorial direction is compatible with the reference bar.
- The Corner gives the brand a usable naming system.

## Current gaps

## Plan

### P0 — prove the editorial engine

1. Select one source recording from Drive.
2. Confirm subject, permissions, guardian status, watermark/attribution, and public use.
3. Produce transcript, captions, cover frame, anchor cut, and three Shorts.
4. Create the first content record and approval packet.

### P1 — rebuild the public slice

1. Replace the older homepage frame with the media headquarters wireframe.
2. Build `/watch` with real items only.
3. Add one CTA: watch, follow, or submit.
4. Add status, rights, privacy, and contact language.

### P1 — verify distribution

1. Create YouTube channel structure and playlists.
2. Upload one approved Short manually.
3. Record title, description, caption, thumbnail, URL, and publish time.
4. Measure retention and CTA response.

### P2 — systematize

1. Add submissions and a protected review queue.
2. Add content records and reusable social templates.
3. Package sponsor/community cuts.
4. Add a lightweight editorial dashboard only when the manual workflow is proven.

## Gauntlet gates

- **Collins:** governing idea before visual polish; the site must feel like a point of view, not a template.
- **Future Champs:** youth/beginning-fighter focus must be visible in the first screen and content taxonomy.
- **Punch By Punch:** people-led conversations, named entry points, and an archive structure must work.
- **Anti-slop:** no generic boxing imagery, invented claims, fake archive cards, empty metrics, or over-written copy.
- **Commercial:** a partner can see the audience, the format, the production capability, and one clear next step.
- **Safety:** no youth likeness or sensitive information goes public without the required approval.

## Rollback

Keep the current static homepage on the main branch until the new media slice passes mobile, rights, link, and content review. Release by route or feature flag where possible. Revert the new route and restore the prior homepage if the anchor package, forms, or public claims fail review.

## Release status

**Not launch-ready.** The strategy and architecture are ready for review. The first publishable media package and rights evidence remain the critical blockers.
