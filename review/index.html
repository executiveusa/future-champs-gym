How review works

Each cut gets a stable ID and a review version. New edits should be uploaded as new files, not silently replace an approved version. A selected clip has its own shareable link using ?clip=. The original production footage stays in Drive and never goes into GitHub.

Privacy and playback

Owner-authenticated previews

The videos remain private on Google Drive; the viewer opens Google's own preview player. If your browser blocks the embedded player, use Open video in Drive. This is an editorial review system, not the final Cloudflare R2 streaming setup for the public website.
